TravelTrucks

A web application for searching, filtering, and booking campervans.

Technologies Next.js TypeScript React TanStack Query Axios CSS Modules Swiper React Icons Features
Browse available campervans Filter campervans by location, body type, engine type, and transmission
Load more campervan cards View detailed information about a campervan Browse campervan images in a
gallery View customer reviews and ratings Book a campervan Receive a booking confirmation
notification Backend API

The application uses the TravelTrucks backend API:

https://campers-api.goit.study

API documentation:

https://campers-api.goit.study/docs

Getting Started Installation npm install Development npm run dev

Open http://localhost:3000 in your browser to see the application.
